## Wireshark Filters
- `ip.addr == ` — filter by IP (source or destination)
- `tcp.port == 80` — filter by TCP port
- `tcp.flags.syn == 1` — filter for SYN packets
- `dns contains "term"` — filter DNS packets containing a string
- `tcp.stream eq X` — isolate a single TCP conversation
